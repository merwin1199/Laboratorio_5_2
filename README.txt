LABORATORIO 5.2 - DISEÑO DE INTERFACES DE USUARIO

Nombre: Merwin Arciniegas Remolina


DESCRIPCIÓN

Este proyecto consiste en la creación de una interfaz web utilizando
HTML5, CSS3 y el framework Bootstrap 5.3.

El objetivo es aplicar los conocimientos aprendidos sobre estructura
HTML, estilos CSS, selectores, modelo de caja, componentes de Bootstrap
y diseño responsivo.


TECNOLOGÍAS UTILIZADAS

- HTML5
- CSS3
- Bootstrap 5.3
- JavaScript de Bootstrap
- Visual Studio Code
- Git y GitHub


PÁGINAS DEL PROYECTO

- index.html: Página principal del proyecto.
- servicios.html: Página donde se presentan diferentes servicios.
- contacto.html: Formulario de contacto.
- style.css: Hoja de estilos personalizada.


RECURSOS

- images/portada_merwin.svg
- images/servicio_merwin.svg


CARACTERÍSTICAS

- Estructura HTML5 semántica.
- Integración del framework Bootstrap 5.3.
- Uso de selectores de elementos, clases e IDs.
- Aplicación de propiedades CSS.
- Aplicación del modelo de caja mediante margin, border y padding.
- Diseño responsivo para computadores, tabletas y celulares.
- Uso de componentes y clases de Bootstrap.
- Formulario de contacto con validación HTML5.
- Navegación entre las diferentes páginas.
- Imágenes SVG creadas para el proyecto.


ESTRUCTURA HTML5

El proyecto utiliza diferentes elementos semánticos de HTML5 como
header, nav, main, section y footer.


DISEÑO RESPONSIVO

Se utilizaron las clases responsivas de Bootstrap y una regla
@media en CSS para adaptar la interfaz a diferentes tamaños
de pantalla.
