Sobre el proyecto

Este proyecto presenta una interfaz web desarrollada con HTML5, CSS3 y Bootstrap. Se aplican diferentes selectores, propiedades CSS, componentes de Bootstrap, modelo de caja y diseño responsivo.

Tecnologías utilizadas

HTML5

Permite organizar el contenido utilizando una estructura semántica.

Estructura

CSS3

Permite aplicar estilos, colores, espacios y diferentes propiedades visuales.

Diseño

Bootstrap

Facilita la creación de interfaces modernas y adaptables a diferentes pantallas.
